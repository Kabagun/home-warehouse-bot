# Home Warehouse Bot

Telegram-бот для общего домашнего склада: таблетки, кофе, корм, бытовая химия и всё, что важно не забыть купить.

## Что умеет

- Несколько домов на одного пользователя: например `Наш дом`, `Родители`, `Дача`.
- Общий дом для нескольких Telegram-аккаунтов через код приглашения.
- Несколько складов внутри одного дома: например `Основной`, `Кухня`, `Ванная`.
- Экран склада с основными действиями: `Добавить`, `Списать`, `Редактировать`, `Обновить`, `Назад`.
- Пополнение и списание существующих позиций без ввода названия: выберите позицию кнопкой и напишите только количество.
- Быстрый текстовый ввод:

```text
+ кофе 2 пачки
- кофе 1
+ корм 1 пакет мин 1
-- горох
```

- Список того, что нужно купить, когда количество меньше или равно минимуму.
- Фоновые напоминания участникам склада.
- Отдельное редактирование позиций: переименовать, изменить минимум, скрыть.
- Управление складами: создать, переименовать, удалить.

## Команды

- `/start` - открыть меню; склад создается только вручную или через приглашение.
- `/stock` - открыть список складов текущего дома.
- `/buy` - показать список покупок по всем складам текущего дома.
- `/homes` - управление домами и кодом приглашения.
- `/newhome Родители` - создать новый дом и переключиться на него.
- `/renamehome Наш дом` - переименовать текущий дом.
- `/join ABC1234` - присоединиться к дому по коду.
- `/help` - подсказка по быстрому вводу.

Быстрый ввод:

- `+ Миг 8` - добавить или пополнить позицию.
- `- Миг 2` - списать количество.
- `-- горох` - скрыть позицию, если покупать ее больше не нужно.

Кнопочный сценарий:

- `Склады` -> выберите склад.
- `Добавить` -> выберите существующую позицию или `Новая позиция`.
- `Списать` -> выберите позицию.
- После выбора позиции напишите только количество: `2`, `2табл`, `500г`.
- `Редактировать` внутри склада открывает редкие действия по позициям.

## Запуск локально

1. Создайте бота через `@BotFather` и получите токен.
2. Скопируйте `.env.example` в `.env`.
3. Заполните `TELEGRAM_BOT_TOKEN`.
4. Установите зависимости и запустите:

```powershell
cd C:\path\to\home-warehouse-bot
python -m venv .venv
.\.venv\Scripts\pip install -r requirements.txt
.\.venv\Scripts\python bot.py
```

## Переменные окружения

- `TELEGRAM_BOT_TOKEN` - токен Telegram-бота.
- `DATABASE_PATH` - путь к SQLite-базе, по умолчанию `home_warehouse_bot.sqlite3`.
- `REMINDER_INTERVAL_HOURS` - как часто повторять напоминания по одной позиции, по умолчанию `24`.
- `REMINDER_CHECK_INTERVAL_SECONDS` - как часто проверять напоминания, по умолчанию `900`.
- `REMINDER_HOURS` - часы, когда можно присылать напоминания, по умолчанию `9,18`.
- `TIMEZONE` - часовой пояс, по умолчанию `Europe/Minsk`.

## Деплой на сервер

Проект лучше держать в `/srv/bots/home-warehouse-bot/app` от пользователя `apps`.

```bash
sudo -u apps -H bash
cd /srv/bots
mkdir -p home-warehouse-bot
cd home-warehouse-bot
git clone <repo-url> app
cd app
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
cp .env.example .env
nano .env
```

После заполнения `.env` установите user systemd service из `deploy/home-warehouse-bot.service.example`.
