# Home Warehouse Bot

Telegram-бот для общего домашнего склада: лекарства, продукты, корм и бытовая химия.

## Возможности

- Несколько домов у одного пользователя: общий дом, родители, дача.
- Общий доступ к дому по коду приглашения.
- Несколько складов внутри дома.
- Единый экран склада с товарами-кнопками и пагинацией.
- Добавление одной позиции или целого списка товаров, по одному товару в строке.
- Карточка товара с быстрыми `−1` и `+1`, точным добавлением и списанием.
- Количество в штуках, таблетках, граммах, килограммах, миллилитрах, литрах и пользовательских единицах.
- Общий список `Купить` по всем складам текущего дома.
- Архив позиций с восстановлением прежнего остатка и минимума; ненужную позицию можно удалить безвозвратно.
- Автоматическое обновление открытых экранов у участников общего дома.
- Работа без автоматических сообщений и напоминаний.

## Навигация

Постоянная клавиатура содержит только главные разделы:

```text
[Склады] [Купить]
[Дом]     [Помощь]
```

Списки и действия текущего экрана находятся под сообщением. Переходы внутри раздела обновляют это же сообщение.

## Быстрый ввод

Последний открытый склад используется для быстрых команд:

```text
+ Миг 8табл
- Миг 2табл
+ корм 9кг мин 500г
- корм 1,5кг
-- горох
```

Длинное тире `— горох`, которое Telegram может подставить вместо двух минусов, тоже переносит позицию в архив.

Минимум по умолчанию равен `1`. Позиция появляется в разделе `Купить`, когда остаток меньше или равен минимуму.

## Команды

- `/start` — открыть бот и постоянное меню.
- `/stock` — открыть список складов.
- `/buy` — открыть общий список покупок.
- `/homes` — открыть дома, участников и код приглашения.
- `/newhome Родители` — создать дом.
- `/renamehome Наш дом` — переименовать текущий дом.
- `/join ABC1234` — присоединиться к дому.
- `/help` — открыть справку.

## Локальный запуск

1. Создайте `.env` рядом с `bot.py`:

```text
TELEGRAM_BOT_TOKEN=токен_бота
DATABASE_PATH=home_warehouse_bot.sqlite3
```

2. Установите зависимости и запустите:

```powershell
cd C:\path\to\home-warehouse-bot
python -m venv .venv
.\.venv\Scripts\pip install -r requirements.txt
.\.venv\Scripts\python bot.py
```

## Проверка

```powershell
python -m py_compile bot.py inventory_bot.py storage.py test_storage.py test_ui.py
python -m pytest -q
```

## Сервер

Проект развёрнут в `/srv/bots/home-warehouse-bot/app` и запускается пользовательским systemd-сервисом `home-warehouse-bot.service` от пользователя `apps`.
